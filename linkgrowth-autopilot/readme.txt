Brand-neutral backlink discovery, qualification, acquisition workflows and backlink monitoring for any WordPress site.

== Description ==

LinkGrowth Autopilot finds websites that could legitimately reference your site, scores them on a transparent model, prepares listing packages and outreach drafts for the channels that allow them, and monitors every backlink it knows about. Each installation keeps its own business profile, settings, provider connections and records; nothing is shared between sites.

The plugin works inside hard limits: it never signs up for accounts, bypasses CAPTCHAs or posts comments, it respects robots.txt, and every generated text passes a claims filter.

Full documentation (installation, configuration, server cron, provider integrations, security, known limitations) is in the docs folder of the source package.

== Installation ==

1. Upload the plugin ZIP under Plugins → Add New Plugin → Upload Plugin, then activate it.
2. Open LinkGrowth → Settings and fill in your business profile.
3. Add the API keys of the providers you use, then turn on the modules you want.
